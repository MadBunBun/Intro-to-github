# Java GUI Calculator

A simple, clean calculator application built using Java Swing.

## Features
- **Basic Arithmetic**: Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`).
- **Additional Utilities**:
  - `C`: Clears the calculation.
  - `DEL`: Removes the last typed digit.
  - `%`: Calculates percentage.
  - `±`: Toggles positive/negative sign.
  - `.`: Decimal point support.
- Division by zero protection (displays `Error`).
- Styled buttons with distinct color coding for operators and actions.

## How to Compile and Run

1. Open your terminal or command prompt in this directory (`Intro-to-github/Calculator`).
2. Compile the Java file:
   ```sh
   javac Calculator.java
   ```
3. Run the application:
   ```sh
   java Calculator
   ```
